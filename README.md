# 🖥️ GEARU — User Management System

### A C# & WPF Desktop Application | SENAI Academic Project

**GEARU** is a desktop user management application developed as part of my studies at **SENAI**, using C#, WPF, and MariaDB.

The project was initially created to practice programming fundamentals, database integration, and desktop application development.

Since there was no strict development deadline, I decided to continue improving the application even after the teacher's evaluation, using it as an opportunity to strengthen my programming skills, explore new technologies, and improve my problem-solving abilities.

Rather than focusing solely on completing an academic assignment, my goal was to build a more complete and functional application through continuous learning and experimentation.

---

## 🚀 Project Overview

GEARU focuses on user account management, combining a desktop interface with database operations and access control.

### Key Features

- User registration, authentication, and account management.
- Password hashing using BCrypt.
- Administrative permissions with hierarchical access levels.
- User profile editing and account deletion.
- Account banning and unbanning.
- Temporary account locking after multiple failed login attempts.
- CAPTCHA verification during login.
- User activity and online status tracking.
- System activity logs for monitoring account changes.
- Light and dark interface themes.
