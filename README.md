# GEARU APPLICATION - SENAI PROJECT

This application was developed while I was studying C# and WPF. It did not have a strict deadline, so I continued working on it after the teacher's evaluation to improve my personal skills and implementation logic.

### TECHNOLOGIES USED IN THIS PROJECT:

---

### 💻 Development & UI
![C#](https://shields.io)
* **C#** was the main programming language used in this project.

![WPF / XAML](https://shields.io)
* **WPF / XAML** was used to build the desktop User Interface (UI).

---

### 🗄️ Database & Connectivity
![MariaDB](https://shields.io)
* **MariaDB** was the relational database engine used to persist all application data.

![MySQL](https://shields.io)
* **MySQL Connector** was the extension used within C# to bridge and connect the application to the MariaDB server.
