# GEARU APPLICATION - SENAI PROJECT

This application was developed while I was studying C# and WPF. It did not have a strict deadline, so I continued working on it after the teacher's evaluation to improve my personal skills and implementation logic.

### TECHNOLOGIES USED IN THIS PROJECT:

* <img src="https://githubusercontent.com" alt="C# Logo" width="25" height="25"/> **C#** was the main programming language used in this project.
* <img src="https://githubusercontent.com" alt="WPF XAML Logo" width="25" height="25"/> **WPF / XAML** was used to build the desktop User Interface (UI).
* <img src="https://celsokitamura.com.br/wp-content/uploads/2019/07/011-XAML-Conceitos-01.jpg" alt="MariaDB Logo" width="25" height="25"/> **MariaDB** was the relational database engine used to persist all application data.
* <img src="https://githubusercontent.com" alt="MySQL Logo" width="25" height="25"/> **MySQL Connector** was the extension used within C# to bridge and connect the application to the MariaDB server.
